## 项目列表

### 1. English Retell — 兴趣内容驱动的英语复述学习 App

用真实的英文内容（视频 / 播客 / 文章）做输入，看完后向 AI 语音复述，AI 以英语教练身份实时对话、纠正、并生成学习记录。

**🔗 [在线体验原型](https://sharon-xx-lin.github.io/XX-demos/english-retell-app/prototype/)** ｜ [需求文档](english-retell-app/docs/需求文档.md) ｜ [调研](english-retell-app/docs/竞品与可行性调研.md)

> 建议用手机打开，或在电脑浏览器按 F12 切换到移动视图（宽度 375px）。

**一句话定位**：市面上的 AI 口语产品用的是自制课程，内容会被"吃完"；内容聚合类产品内容无限但没有输出环节。这个产品落在两者交叉处——**用真实世界的内容做输入，用 AI 做输出的评价与纠错**。

**过程中做的几个判断**

- **调研先于设计**：查了 YouTube 开发者政策后发现，第三方 App 禁止下载/缓存音视频、禁止对嵌入播放器观看收费。这直接否掉了"离线下载"功能和"订阅才能看素材"的商业模式。
- **API 配额否掉了原始方案**：原设想是"输入主题 → AI 实时检索"，但 YouTube Data API 默认每天仅够约 100 次搜索且无法付费扩容。改为"预建主题素材库 + 语义匹配"，并据此补充了运营后台需求。
- **纠错从应试导向改为实用导向**：初版借用 IELTS 四维评分，但这是考试框架，会让纠错滑向"主谓一致""动名词"这类应试内容。重构为以"能否有效沟通"为核心的四维，并明确"不影响理解的语法细节不纠"。
- **打卡机制反向设计**：streak 是留存最强的功能，但断签羞耻会导致"全有全无"式弃用。采用"连续记录不清零 + 补签需完成真实学习兑换"，去掉归零惩罚与施压推送。
- **语音全英文**：AI 对话中不说中文，界面的中文翻译默认隐藏——否则用户会直接读中文、跳过听英文，语言环境等于没建立。
