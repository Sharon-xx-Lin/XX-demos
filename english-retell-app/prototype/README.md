# 交互原型

## 怎么看

- **在线**：https://sharon-xx-lin.github.io/XX-demos/english-retell-app/prototype/
- **本地**：下载 `index.html`，双击用浏览器打开即可（单文件，无需安装任何东西）

建议用手机浏览器打开，或在电脑上按 F12 → 点击手机图标切换移动视图（宽度 375px）。

## 包含的页面

| 页面 | 说明 |
|------|------|
| onboarding | 水平自评 + 兴趣选择，两步可跳过 |
| 首页 | 今日推荐、一键进入学习 |
| 素材消费 | 播放器 + 倍速 + 字幕对照 |
| AI 复述对话 | 通话式界面，语音复述与实时反馈 |
| 学习报告 | 更自然的说法、可复用表达、对话记录 |
| 数据 | 打卡热力图（按学习时长分档）、主题分布 |
| 社区 | 素材推荐流 |
| 我的 | 报告历史、词表、偏好、隐私设置 |

## 关于源码

`src/` 是页面源码（React + TypeScript）。`index.html` 是打包后的单文件版本，包含全部代码与样式，可离线运行。
