# English Retell

兴趣内容驱动的英语复述学习 App · 产品设计与原型

**🔗 [在线体验原型](https://sharon-xx-lin.github.io/XX-demos/english-retell-app/prototype/)**

---

## 产品是什么

输入一个感兴趣的主题（AI 资讯、KPOP、职场沟通…），系统给出经筛选的英文素材（视频 / 播客 / 文章，有长有短）。看完或听完后，用英语向 AI 复述内容，AI 以英语教练身份**用语音实时对话**、追问、并在自然回应中带出正确说法。结束后自动生成学习记录。

完成一次「消费素材 → 复述」即算完成一次打卡。

## 为什么做这个

成年人的英语学习失败，多数不是方法不对，而是**读不下去**——教材枯燥，学习被设计成一件需要意志力对抗的事。

产品理念是把这件事反过来：

- **Content is king，学习 = 内容消费**。不自制教材，而是帮用户找到真正想看的内容
- **只要学习了，就是胜利**。不做质量门槛、不做惩罚性反馈
- **「可持续」比「效率」重要**。拒绝任何以提升单次效率为名、但增加心理负担的设计
- **把「内耗」变成「外耗」**。学不下去时，产品应归因于"素材不够吸引人"并帮用户换内容，而非提示"再坚持一下"

## 差异化定位

| | 内容来源 | 内容会耗尽 | 口语输出 | 复述任务 |
|---|---|---|---|---|
| Duolingo Max | 自制课程 | 会 | ✓ 自由对话 | ✗ |
| Speak | 自制课程 | 高阶会 | ✓ 多形态 | ✗ |
| LingQ | 用户导入 | 不会 | ✗ | ✗ |
| Speechling | 自制句库 | 会 | ✓ 复读 | ✗ |
| **本产品** | **真实公开内容** | **不会** | **✓** | **✓** |

调研的五个竞品中，没有一个做「消费真实内容后复述给 AI」这个任务形态。

## 页面结构

```
底部 Tab（4 个并行入口）
├─ 首页      主题 + 今日推荐 + 一键开始
├─ 数据      打卡热力图（按学习时长分档）+ 主题分布
├─ 社区      素材推荐流
└─ 我的      报告历史 / 词表 / 偏好 / 隐私

流程内页面（栈式推入，隐藏 Tab 栏）
素材消费 → AI 复述对话 → 学习报告
```

## 几个关键设计决策

### 合规约束直接改写了功能设计

查 YouTube 开发者政策后确认三条硬约束，都不是"建议"而是"违反会被封禁"：

1. **禁止下载、缓存、转存音视频，禁止离线播放** → 通勤无网场景只能靠文本素材承接
2. **禁止对「在嵌入播放器中观看内容」收费** → 付费点不能是"订阅才能看素材"，只能落在 AI 复述、报告等自有能力上
3. **字幕正文需内容所有者授权才能获取** → "不允许非英文字幕"这条筛选只能靠字幕轨语言元数据判断

### API 配额否掉了原始方案

原设想是"用户输入主题 → AI 实时检索素材"。但 YouTube Data API 默认每天 10,000 units，单次搜索消耗 100 units，即**全平台每天仅约 100 次搜索**，且无法付费扩容。

结论：面向用户的产品语言可以保留"AI 为你检索"，但实现必须是**预建主题素材库 + 语义匹配**。这个约束又反推出一整套素材运营后台需求（白名单源管理、批量入库、审核工作台、元数据 30 天刷新、短素材库存告警）——没有它，产品首期就是空壳。

### 纠错从应试导向改为实用导向

初版借用 IELTS 口语四维（流利度与连贯性 / 词汇资源 / 语法广度与准确度 / 发音）做评价框架。但 IELTS 是**考试评分框架**，沿用它会让纠错必然滑向"主谓一致""动名词作主语"这类应试内容。

重构为以「能否有效沟通」为核心的四维：内容传达 / 表达自然度 / 交流流畅度 / 可听懂度。并明确纠错取舍：

- **不纠**：三单 -s、冠词、可数不可数、时态小偏差、介词细微误用（不影响理解）
- **必纠**：中式英语直译、影响理解的用词错误
- 纠错上限 2 条，禁用一切语法术语

### 打卡机制做了反向设计

streak 是行业公认留存最强的单点功能，但断签羞耻会导致"全有全无"式弃用——这是打卡类产品的经典流失曲线，也与"不要 PUA 自己"的理念直接冲突。

采用的方案：

- 主视觉是**累计天数/次数**（只增不减），连续记录降为第二行
- 断签**不归零**，降级为"本月坚持 X 天"
- 补签**必须通过完成一次真实学习来兑换**（不是点击即得），限最近 3 天、每月 3 次
- 热力图空缺日用中性灰，不用红色
- 禁止归零动画、施压推送、排行榜

### 语音全英文，中文翻译默认隐藏

AI 对话中不说任何中文——语言环境是产品价值的一部分。听不懂时用**更简单的英文重说**（rephrase），而不是切换成中文。

关键是配套改动：界面上的中文翻译从"默认显示"改为"点击才展开"。否则用户会直接读中文、跳过听英文，语言环境等于没建立。

### 对话中不纠错，用 recast 代替

语音对话里逐句纠错会打断交流节奏，而且英文语法解释**用听的记不住**。所以采用二语习得中的 recast（重铸）：

> 用户：It **talk** about why **make AI chip** is difficult.
> 教练：Right — it **talks about** why **AI chips are so hard to make**. What surprised you most?

AI 不打断、不点评，在自然回应里把正确说法带出来。显性的文字纠错全部放到会话结束后的学习报告里，可以反复看。
